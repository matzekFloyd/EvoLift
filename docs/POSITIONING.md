# Positioning

Public home `/`. Phase 5 ran from the phase brief on 2026-10-26 (`storybrand-messaging` is not installed). The lifter is the hero. EvoLift is the guide.

## Brand Script (StoryBrand)

| Piece | Statement |
|---|---|
| Character | A lifter who wants the sets recorded. |
| External problem | The log happens after the workout, when the numbers are already fuzzy. |
| Internal problem | The log gets in the way of the workout. |
| Philosophical problem | A log should keep up with the lifter. This stays off the page. |
| Guide, empathy | Logging has to fit between sets. |
| Guide, authority | The page states the cost in plain words. No invented proof. |
| Plan | Create an account. Log during the workout. Come back to the progress. |
| Direct CTA | Start lifting. It opens Register. |
| Transitional CTA | None on the page. One button. The account note is not a second action. |
| Failure | The workout ends and the numbers are a guess. |
| Success | The sets are logged before you leave. |

## One-Liner

We help lifters who struggle with a log that gets in the way of the workout to record sets while they train.

Commander's Intent — the one line to remember: **Log each set before the next one starts.**

“Keeps up” stays in the brand script as the promise. It is not the heading.

## Key Messages

SUCCESs is a count out of 6: simple, unexpected, concrete, credible, emotional, story. No timing stat was invented.
